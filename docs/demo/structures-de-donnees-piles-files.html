Structures de données – Chapitre 3 : Piles et files

Faculté des sciences, première année, licence d'informatique

3.1 La pile

Une pile est une structure de données où le dernier élément ajouté est le premier retiré. On parle de structure LIFO, pour « dernier entré, premier sorti ».

L'empilement est l'opération qui ajoute un élément au sommet de la pile. Le dépilement est l'opération qui retire l'élément situé au sommet de la pile et le renvoie.

Le sommet désigne le dernier élément ajouté, le seul auquel on peut accéder directement.

Le débordement de pile est l'erreur produite quand on empile dans une pile qui n'a plus de place libre. Le dépassement par le bas est l'erreur produite quand on dépile une pile vide.

La pile d'appels d'un programme est une pile d'appels de fonctions : quand une fonction se termine, l'appel le plus récent est retiré en premier.

La fonction « annuler » d'un éditeur de texte utilise une pile : la dernière modification faite est la première annulée.

3.2 La file

Une file est une structure de données où le premier élément ajouté est le premier retiré. On parle de structure FIFO, pour « premier entré, premier sorti ».

L'enfilement est l'opération qui ajoute un élément à la fin de la file. Le défilement est l'opération qui retire l'élément situé en tête de la file.

3.3 Variantes de la file

Une file de priorité est une file où chaque élément a une priorité, et où l'élément de plus haute priorité est retiré en premier, quel que soit son ordre d'arrivée.

Un tampon circulaire est un tableau de taille fixe utilisé comme une file, où la fin revient au début quand elle atteint la dernière case.

3.4 Listes chaînées

Une liste chaînée est une suite de nœuds où chaque nœud contient une valeur et un pointeur vers le nœud suivant.

La tête désigne le premier nœud de la liste chaînée ; le dernier nœud pointe vers rien.

Une liste doublement chaînée est une liste chaînée où chaque nœud stocke aussi un pointeur vers le nœud précédent, ce qui permet de la parcourir dans les deux sens.

Une pile peut être réalisée avec une liste chaînée : on empile et on dépile en tête de liste, en temps constant.

3.5 À retenir

Une pile retire toujours l'élément le plus récent, une file retire toujours l'élément le plus ancien. Le choix entre pile et file dépend de l'ordre dans lequel les éléments doivent être traités.
